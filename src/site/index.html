Nhật ký thi công – Excel Add-in

Phiên bản __APP_VERSION__

Add-in lập nhật ký thi công theo ngày từ bảng tiến độ và xuất lên biểu mẫu "Tình hình thi công hàng ngày".

Tải manifest.xml

Cài đặt nhanh (Excel Desktop Windows)

  1. Tạo một thư mục chia sẻ trong mạng nội bộ (ví dụ \\TEN-MAY\NKTC_Addin) và lưu file manifest.xml vào đó.
  2. Excel → File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs: nhập đường dẫn thư mục chia sẻ → Add catalog → tích Show in Menu → OK.
  3. Đóng và mở lại Excel.
  4. Insert → My Add-ins (hoặc Get Add-ins) → thẻ SHARED FOLDER → chọn Nhật ký thi công → Add.
