Nhật ký thi công – Excel Add-in

Phiên bản __APP_VERSION__

Add-in lập nhật ký thi công theo ngày từ bảng tiến độ và xuất lên biểu mẫu "Tình hình thi công hàng ngày".

Tải bộ cài (Windows)

NhatKyThiCong_Setup.exe · Excel 2016 trở lên / Microsoft 365 · không cần quyền quản trị · các phiên bản: GitHub Releases

Cài đặt

  1. Lưu và đóng Excel.
  2. Chạy file NhatKyThiCong_Setup.exe vừa tải. Nếu Windows hiện "Windows protected your PC": bấm More info → Run anyway.
  3. Ở bước cuối giữ dấu tích Mở Excel và kích hoạt add-in → Hoàn tất. Excel mở kèm khung add-in (nếu Excel hỏi tin cậy add-in → chọn Trust / Tin cậy).
  4. Từ đó dùng nút Nhật ký thi công trên tab Home.

Cập nhật

Add-in tự cập nhật mỗi lần mở (cần Internet). Khi có bản mới, add-in hiện thông báo; chỉ cần chạy lại bộ cài nếu thông báo yêu cầu.

Không thấy add-in?

Không thấy nút trên tab Home: mở Start menu → Nhật ký thi công (Excel) để kích hoạt lại, hoặc Insert → My Add-ins → Developer Add-ins → Nhật ký thi công → Add.

Gỡ cài đặt

Đóng Excel → Settings → Apps → Installed apps → Nhật ký thi công (Excel add-in) → Uninstall.

Cài cho cả nhóm qua thư mục chia sẻ (nâng cao)
  1. Tạo thư mục chia sẻ trong mạng nội bộ (ví dụ \\TEN-MAY\NKTC_Addin) và lưu manifest.xml vào đó.
  2. Excel → File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs: nhập đường dẫn thư mục → Add catalog → tích Show in Menu → OK.
  3. Đóng và mở lại Excel → Insert → My Add-ins → thẻ SHARED FOLDER → Add.
